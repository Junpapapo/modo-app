# Modo Public Web Portal (GitHub Pages)

This folder contains the complete, standalone public web assets for **Modo (mōdo)**:

## 📁 Directory Structure
```
modo-app/
├── index.html          # Modern Minimalist Landing Page
├── privacy/
│   └── index.html      # Privacy Policy (Dual EN/KO, AdMob & SQLite compliant)
├── terms/
│   └── index.html      # Terms of Service
└── README.md
```

## 🚀 Quick Setup for GitHub Pages (Public Repo)

1. Create a new **Public** repository on GitHub: `modo-app` (or `modo-public`).
2. Upload/Push the files inside this `modo-app/` folder to the root of your new public repository.
3. In your new repo, go to **Settings ➔ Pages**:
   - Source: **Deploy from a branch**
   - Branch: **`main`** / **`/(root)`**
   - Click **Save**.
4. Your official URLs will be live at:
   - **Landing Page:** `https://junpapapo.github.io/modo-app/`
   - **Privacy Policy:** `https://junpapapo.github.io/modo-app/privacy/`
   - **Terms of Service:** `https://junpapapo.github.io/modo-app/terms/`

Copy the **Privacy Policy URL** into Google Play Console's Privacy Policy field.
